## 3. 经济事实（决策依据，全部实测）

1. **顶级饵最赚**：净/杆 ~1981 金（含卖鱼价值），直金现金流为负 → **必须卖鱼兑现**。
2. **力量是阶梯函数**：不跨档 = 0 收益。下一有效档：稀有 11500（+60.8 金/杆）。
3. **强化/买装备都跨不了档（修正 2026-08-13）**：配装1 全强最多 +373 力（1794 万）不够 634；
   市场神话装备 18/20 件综合属性不如现配装（现配装已有神话戒指力788+神话绑腿力488）。
   **跨档唯一现实途径 = 开箱**（神话/奇异装备替换低力槽位 + 遗物重铸洗力）。
4. **遗物（4234）只留给开箱后重铸装备**（75/次）；不买 buff（渊流臂力 II 150/次是浪费）、不买头像。
5. **奥术宝箱期望 ~114 万/箱**（奇异实测 3300~8000 万重算），赌奇异 0.9%
   = 平均 111 箱（1.11 亿）才出一个。50 箱有 36% 概率至少中 1 个。
6. **奥秘保底已满**：最大彩票，出货价值 550~1500 万/条，**死守顶级饵**。
   （软保底不是 50%——奥秘软保底阈值 ≈32000/硬保底 83621 = **38% 处**；
   maxDry 越过后恒等于 currentDry；历史佐证上次软保底后 ~100 杆就出货。
   奇异软保底 13524 在硬保底 10779 之后，实际以硬保底为准。）
7. **奥术宝箱也有硬保底**（前端公告 0.17.4）：连续未开出奥术装备，**第 1500 箱必出**
   = 15 亿金币。50 箱目标不受影响，但长期要心里有数。
8. **专精**：完成档位 → 图加成 + 专精点 → 天赋（渊博垂钓者 +5% 经验等）。
   b_005 星根洞窟（700bp 加成）传说/神话档最近完成。

## 6. 工具箱速查（常用命令）

全部只读，放心跑；涉及花钱/写操作的都标了 ⚠️。

```bash
# 状态核对（发橘子前先跑这个）
python3 gaming/check.py                     # 快速状态
python3 gaming/check.py --full              # 加专精/任务/活动
python3 gaming/check.py --diary             # 对比网络日记算速率 + 更新游戏日记

# 奥术宝箱
python3 gaming/open_chests.py --status      # 金币 + 宝箱库存（只读）
python3 gaming/open_chests.py --simulate 50 # 假开 50 箱：本地模拟，不发服务器（预览出货/概率）
python3 gaming/open_chests.py --buy 50 --open --yes   # ⚠️ 真买 50 + 开 50（需橘子指挥+确认）

# 扫货估价
python3 gaming/shop_mastery.py b_009        # 专精鱼扫货：缺什么、市场价、补完多少钱
python3 gaming/shop_mastery.py --all        # 所有已解锁地图
python3 gaming/shop_gear.py                 # 市场扫装备：对比配装找能加力的装备
python3 gaming/shop_gear.py --rarity mythic --min-gain 100   # 只看神话、+100力以上
```

**说明**：
- `--diary` 速率 = 与上次网络日记（Issue #3）对比；PATCH 更新有 **30 分钟门槛**（间隔 <30 分只读不写）。
- `--simulate` 按宝箱真实掉率（精良5% 稀有35% 史诗40% 传说16% 神话3% 奇异0.9% 奥术0.1%）本地蒙特卡洛。
- `shop_mastery.py` 建议规则：市场挂价 ÷ 鱼基础价（`sellPrice`）——💎捡漏(<1×) ✅便宜(<1.5×) 正常(1.5~3×) ⚠️贵(≥3×)。
- `shop_gear.py` 会算「单件最佳」和「可买组合」能否跨 11,500 稀有档；当前结论：**市场扫装备跨不了档，等开箱**。
