## 一、检查节奏（回答「多久提醒你看一次」）

### 常规节奏：每 8 小时一次（一天 3 次）

```bash
python3 gaming/check.py            # 常规
python3 gaming/check.py --full     # 隔天一次，加专精/任务/活动
```

每次把输出发我，我核对：
1. **今日杆数**：半天 ≥6000 / 整天 ≥12000，低于预期查原因
2. **金币**：对比里程碑
3. **保底**：奥秘有没有出货（currentDryCasts 回落）→ 出货了要确认卖/留
